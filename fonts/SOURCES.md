# Bundled fonts

Unmodified variable font files downloaded 2026-09-11 from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay

The corresponding SIL Open Font License notices are included beside the files.
Fonts are served locally; page visits do not need requests to Google Fonts.
